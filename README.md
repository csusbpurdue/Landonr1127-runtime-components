# Runtime Components

A repository for my environment configuration (rc) files. It allows me to quickly set up my settings on a new server or computer.

## Configuration Files
* **.bashrc** - Settings for Bash terminal
* **.zshrc** - Settings for Zsh terminal (Mac)
* **.vimrc** - Settings for Vim text editor
* **.gitconfig** - Global Git profile settings
* **.gdbinit** - Settings for GDB debugger

## How to Install
Run `./install.sh` to copy these files to your home directory.
